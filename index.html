何をしますか？

The world moves through events and state transitions.

“The world can be represented by state transitions and events.”

Factories, robots, cars, AGVs, and people are all systems of connected events. FACT SIM models this structure directly so you can validate decisions before deployment.

Factories Robots Cars AGVs People

States

Idle, process, wait, down, blocked, reserved, occupied.

Events

Arrivals, handoffs, releases, merges, splits, routing, downtime.

Decisions

Validate the reason a line meets takt or fails before equipment is purchased.

Built for analysis, not presentation-only animation.

Node-Based Modeling

Build systems visually using a graph model.

Discrete-Event Engine

Simulate state transitions and event timing accurately.

Second-Level Precision

Analyze process flow with practical temporal resolution.

Browser Native

Run instantly with no installation or license server.

Lightweight

Fast iteration on everyday laptops and workstations.

Open Source

Transparent architecture for extension and audit.

Model real systems with discrete-event logic.

Share URL

Share URL compresses graph JSON and embeds it in the URL hash (#g=...).

Graph data is not sent to external servers. Shared data stays in this URL string.

URL length limits vary by browser/environment, so very large graphs may not open via URL.
